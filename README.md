# NationiSScanner

NationiSScanner — это высокопроизводительный сетевой сканер, написанный на Python, который позволяет быстро проверять заданный диапазон IP-адресов на наличие открытых портов. Инструмент оптимизирован для многопоточного сканирования и масштабируется даже при большом количестве IP.

---

## Особенности

- **Высокая производительность:** Использование `ThreadPoolExecutor` для параллельного сканирования и батчей IP-адресов.
- **Настраиваемые параметры:** Возможность указания диапазона IP, портов, количества потоков и файла для вывода результатов.
- **Инкрементальное сохранение:** Результаты сканирования сохраняются по мере обработки IP-адресов.
- **Статистика в реальном времени:** Отдельный поток отображает статистику сканирования (скорость, общее количество IP и найденные открытые порты).
- **Обработка прерываний:** Корректное завершение работы при нажатии Ctrl+C с сохранением уже полученных результатов.

## Использование

Скрипт запускается из командной строки с обязательными параметрами для указания начального и конечного IP-адресов. Также можно задать порты, количество потоков и файл для вывода результатов.

### Пример базового запуска:

```bash
python ultra_scanner.py 192.168.1.1 192.168.1.255
```

### Доступные аргументы:

- **start_ip** – Начальный IP-адрес диапазона сканирования.
- **end_ip** – Конечный IP-адрес диапазона сканирования.
- **-p, --ports** – Порты для сканирования (по умолчанию: `80, 8080, 554, 8554, 37777, 88, 8888, 1935, 9000`).
- **-t, --threads** – Количество потоков (по умолчанию: `1024`).
- **-o, --output** – Файл для сохранения результатов сканирования в формате JSON.

### Пример с дополнительными параметрами:

```bash
python ultra_scanner.py 192.168.0.1 192.168.0.255 -p 22 80 443 -t 512 -o results.json
```
